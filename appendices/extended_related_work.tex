\section{Extended Related Work}
\label{app:extended-related-work}

This appendix records broader 2026 context that is useful for positioning but
not needed for the main argument.

\paragraph{Modern lens variants.}
Recent work extends lens-style inspection beyond the original next-token logit
lens. Future Lens asks whether a single hidden state predicts later tokens
\citep{pal2023future}, while LogitLens4LLMs updates logit-lens tooling for
modern Hugging Face model families \citep{wang2025logitlens4llms}. Other work
targets settings where direct single-token decoding is limited: ContextualLens
and LatentLens use richer contextual representations for vision-language models
\citep{phukan2025contextuallens,krojer2026latentlens}, and Indic-TunedLens
adapts tuned-lens-style decoding to Indian languages
\citep{panchal2026indictunedlens}. These methods are useful context because
they keep the hidden-state inspection interface current. They mainly vary what
is decoded from a representation or where the interface is applied; SRP instead
factorizes the model's own LM head and uses scalar readout targets to assign
signed sparse readout-feature terms.

\paragraph{Recent sparse-feature infrastructure.}
Beyond the core SAE and dictionary-learning work cited in the main text, recent
benchmarks and releases have made sparse-feature analysis more standardized and
model-family specific. SAEBench evaluates sparse autoencoders for language-model
interpretability, while Gemma Scope and Qwen-Scope release activation SAEs for
Gemma and Qwen-family models
\citep{karvonen2025saebench,lieberum2024gemmascope,deng2026qwenscope}. Recent
weight-based SAE interpretation also studies how activation-SAE features
interact with model weights and output-token effects
\citep{liu2026weightbasedsae}. This is close in spirit to SRP's emphasis on
readout-side evidence, but the fitted object is different. Those works analyze
activation features and their downstream roles; SRP fits the sparse dictionary
directly to unembedding rows, making LM-head replacement, scalar readout-target
reconstruction, and explicit residual terms part of the readout decomposition.
