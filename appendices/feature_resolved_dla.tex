\section{Feature-Resolved DLA}
\label{app:feature-resolved-dla}

\Cref{sec:feature-resolved-component-decomposition} uses Sparse Readout Prism
terms inside ordinary direct-logit-attribution decomposition as an additive
decomposition identity
\citep{elhage2021framework,wang2022ioi,nguyen2024logitprisms}. This appendix
states the identity. For a selected readout direction
\(q=\sum_t \alpha_t w_t\), let \(m_\alpha=\sum_t\alpha_t\) and
\(r_q=\sum_t\alpha_t r_t\). Sparse Readout Prism gives
\[
    q = m_\alpha\mu+\sum_i \beta_i(q)d_i + r_q ,
\]
where \(d_i\) is an SAE decoder direction and \(r_q\) is the readout
reconstruction residual for the selected readout score. The displayed scores
below are zero-sum vocabulary-mean or token-token contrasts, so \(m_\alpha=0\)
and the offset term cancels; raw token logits would retain it. At a hidden state \(h\),
\[
    h^\top q
    =
    m_\alpha h^\top\mu
    +
    \sum_i \beta_i(q)h^\top d_i
    +
    h^\top r_q .
\]
Under the fixed final-normalization convention used for DLA, decompose
\(h\approx\sum_c h_c\). The component offset, SAE feature, and residual terms
are
\[
    \begin{aligned}
    O_c(q)&=m_\alpha\,h_c^\top\mu,\\
    M_{c,i}(q)&=\beta_i(q)\,h_c^\top d_i,\\
    R_c(q)&=h_c^\top r_q .
    \end{aligned}
\]
For the zero-sum contrasts used in the figures, \(O_c(q)=0\). We therefore report
two separate gaps: the DLA additivity error between \(h^\top q\) and
\(\sum_c h_c^\top q\), and the readout SAE residual \(h^\top r_q\) (or its
componentized version \(\sum_c R_c(q)\) under the same DLA approximation).
The difference between \(h^\top q\) and a componentized feature-only sum
\(\sum_{c,i}M_{c,i}(q)\) contains both sources unless the residual and DLA
additivity terms are included separately.

The main display uses the pairwise logit difference
\(q=w_{\mathrm{verify}}-w_{\mathrm{assume}}\), for which
\(\beta_i(q)=z_{\mathrm{verify},i}-z_{\mathrm{assume},i}\). The same identity
also covers the vocabulary-mean contrast \(q=w_{\mathrm{verify}}-\bar{w}\),
which decomposes one resolved token's readout above the vocabulary-mean row
across residual-stream components. The component view is an additive
decomposition over a realized forward pass; separate interventions complement
it for circuit analysis \citep{geiger2023causalabstraction}.

\Cref{fig:qwen-prism-dla-verify-token-app} shows the vocabulary-mean contrast
version. The prompt is the same source-verification prompt; the selected
score is \(h^\top(w_{\mathrm{verify}}-\bar{w})\), whereas the main figure
uses the token-token logit difference.
