\section{Experimental Setup}
\label{sec:experimental-setup}

\paragraph{Claim-to-test map.}
The experiments proceed in three stages: testing the SRP basis, then selected
targets, then validation-gated use cases.
\emph{Basis tests.} Held-out row reconstruction and LM-head replacement on C4
hidden states \citep{raffel2020exploring,dodge2021documenting} check whether
the readout SAE preserves the readout it replaces.
\emph{Target tests.} Target reconstruction, sign preservation, and relative
error check whether a selected score is reconstructed well enough to read its
feature bars.
\emph{Baseline tests.} Comparisons with nearest-row ridge, PCA, shuffled
sparse codes, and random sparse patterns check whether learned token-row
structure improves over dense low-rank structure, lexical neighborhoods, or
sparse capacity alone.
Sign flips, large relative error, weak replacement fidelity, or parity with
baselines mark failure modes. Unless explicitly labeled as interventions, all
downstream analyses are readout-level and make no direct claims about
generation behavior.

\paragraph{Models, selection, and units.}
The model suite covers Qwen3.5 \citep{qwen35collection}, Gemma-4
\citep{gemma4official,gemma4collection}, Ministral \citep{liu2026ministral3},
and reasoning-distilled Qwen/Llama readouts \citep{deepseekai2025deepseekr1},
spanning tokenizer family, output geometry, scale, and post-training recipe.
Qualitative displays use one fixed low-error setting, Qwen3.5-2B \(32\times\),
\(k=256\), where \(D=32d_{\mathrm{model}}\) is dictionary width and \(k\) is the
TopK active-feature budget. We score final LM-head inputs and select readout SAEs
by held-out row reconstruction, replacement fidelity, and sparse code usage. We
reserve held-out logit-difference targets for downstream target-fidelity checks.
Replacement uses 10,000 neutral C4 continuations per model; target-fidelity
evaluations use preconstructed prompt/target sets with fixed linear
coefficients, split assignment, and tokenization filters. These splits keep model
selection separate from target-fidelity evaluation. Model identifiers and details
are in Appendix~\ref{app:model-suite-selection}.

\paragraph{Reading local score decompositions.}
Each display names its scalar target and reports the original score, sparse
feature sum, residual, relative error, and sign status. Score-independent
appendix figures rank feature projections \(h^\top d_i\) before target
selection; Appendix~\ref{app:robustness-controls} summarizes controls and
token-level audits.
