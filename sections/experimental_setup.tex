\section{Evaluation Setup}
\label{sec:experimental-setup}

\subsection{Research Questions}
\label{subsec:evaluation-questions}
The experiments first calibrate whether SRP accounts are usable
(\Cref{subsec:metrics-and-baselines}); conditional on these checks, the
analysis asks five questions:
\begin{description}[leftmargin=!,labelwidth=2.7em]
    \item[RQ1:] What does SRP add to an ordinary logit-lens preference?
    \item[RQ2:] How does the chosen readout question change the sparse account?
    \item[RQ3:] Which readout features carry each side of token-vs-token
    preferences?
    \item[RQ4:] How does prompt context reweight readout-feature projections for
    a fixed token row?
    \item[RQ5:] Can the same readout-feature terms compose with residual-stream
    attribution and constrained readout-side edits?
\end{description}

\subsection{Models, Readout SAEs, and Held-Out Targets}
\label{subsec:models-and-targets}

\paragraph{Model suite.}
The suite covers Qwen3.5 \citep{qwen35collection}, Gemma-4
\citep{gemma4official,gemma4collection}, Ministral \citep{liu2026ministral3},
and reasoning-distilled Qwen/Llama readouts \citep{deepseekai2025deepseekr1},
spanning tokenizer family, output geometry, scale, and post-training recipe.
Model identifiers and details are in
Appendix~\ref{app:model-suite-selection}.

\paragraph{Qualitative display setting.}
Qualitative examples use one fixed low-error setting, Qwen3.5-2B
\(32\times\), \(k=256\), where \(D=32d_{\mathrm{model}}\) is dictionary width
and \(k\) is the TopK active-feature budget.

\paragraph{Dictionary selection and held-out score checks.}
We fit readout SAEs on final LM-head inputs and select them by held-out row
reconstruction, replacement fidelity, and sparse code usage, then reserve
held-out logit differences for downstream score-reconstruction checks.
Replacement uses 10,000 neutral C4 continuations per model
\citep{raffel2020exploring,dodge2021documenting}; score-reconstruction
evaluations use preconstructed prompt/score sets with fixed linear
coefficients, split assignment, and tokenization filters. These splits keep
dictionary selection separate from score-reconstruction evaluation.

\subsection{Metrics, Baselines, and Operating Regimes}
\label{subsec:metrics-and-baselines}
Calibration uses three checks: basis, score, and baselines.
\emph{Basis metrics.} Held-out row reconstruction and LM-head replacement on C4
hidden states check whether the readout SAE preserves the readout it replaces.
\emph{Score metrics.} Score reconstruction, sign preservation, and relative
error check whether a selected logit, contrast, or margin is reconstructed well
enough to read its feature bars. \emph{Baselines.} Comparisons with nearest-row
ridge, PCA, shuffled sparse codes, and random sparse patterns check whether
learned token-row structure improves over dense low-rank structure, lexical
neighborhoods, or sparse capacity alone. Sign flips, large relative error,
weak replacement fidelity, or parity with baselines mark failure modes.

\paragraph{Scope and interpretation rule.}
All downstream analyses are readout-level: they describe how the LM head
decomposes a selected score, not how the model generates. We read feature bars
only when the selected score is reconstructed with small residual and, for
signed contrasts, the reconstructed and exact scores agree in sign. Feature
labels are descriptive summaries, while feature ids, signed contributions, and
residuals are the measured objects; the only place we make any claim about
generation behavior is the constrained-edit intervention in
\Cref{subsec:constrained-readout-edits}.
