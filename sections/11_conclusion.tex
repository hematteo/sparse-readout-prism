\section{Conclusion}

Sparse Readout Prism is a sparse feature decomposition for logit-lens readouts.
It factorizes the final unembedding, or LM head, into sparse token-row
coefficients and shared readout directions. For a hidden state, this yields a
readout feature projection vector before target selection; a scalar readout
target---a token logit, reference contrast, pairwise or group contrast, or local
margin---then turns those projections into signed feature contributions for the
chosen score, with offset and reconstruction residual reported alongside the
feature sum.

The experiments test when this factorized readout can be interpreted. LM-head
replacement fidelity, target reconstruction, sign agreement, and support
baselines identify regimes where the sparse factorization preserves the original
readout behavior and selected scalar targets. In those regimes, SRP separates
target choice from context reweighting: changing the target changes the
coefficients \(\beta_i(q)\), while changing the prompt changes the projections
\(p_i(h)\). This separation shows why the same hidden state can yield different
support under different readout targets, and why the same token row can be
reweighted across prompt contexts.

SRP therefore moves lens-style readouts from atomic vocabulary scores to
feature-resolved readout decompositions. The same signed terms apply beyond
curated token pairs, compose with direct logit attribution, and can select
readout-side directions that move held-out lexical scores. SRP does not by
itself establish causal mechanisms or sequence-level behavior, but it supplies a
calibrated readout-linear basis for asking those questions with explicit
residuals and fidelity diagnostics.
