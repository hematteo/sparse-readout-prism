\begin{abstract}
Vocabulary lenses read hidden states through the LM head and report
tokens. The token is an ambiguous unit for that report: one token can be
supported by different structure in different contexts, and different
tokens by the same structure, so a lens reading can change without the
computation behind it changing. We present Sparse Readout Prism (SRP), a
sparse factorization of the LM head that reads any selected token logit
or logit difference as signed contributions over shared \emph{readout
features}, plus an explicit residual, in logit units. The basis is fit
from the weights alone, so unlike activation dictionaries it exists
before any prompt and one dictionary serves every layer and lens. On the
six of eight models that pass a head-replacement check, SRP reconstructs
selected scores faithfully on \textbf{0.72--0.81} of contrasts, ahead of
every baseline built on LM-head row geometry, and predicts the effect of
deleting single features (\(r^2=0.83\)--\(0.93\)). The payoff is a
reading that survives the surface: English- and Chinese-fitted Jacobian
lenses report different languages on identical hidden states, yet the
same SRP feature stays dominant on \textbf{77 of 80} prompts. What a
lens reports follows its fitting corpus---\emph{corpus
conditionality}---and is not, by itself, evidence of a matching
intermediate computation.

\end{abstract}
