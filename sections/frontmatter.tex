\begin{abstract}
Lens-style methods report which vocabulary tokens a hidden state favors, but
each token logit or contrast remains a single dense dot product with the LM
head; the readout directions that raise or lower that score, and the error a
sparse account would incur, stay hidden. Sparse Readout Prism (SRP)
factorizes LM-head rows into sparse token-row coefficients over shared
readout directions, projects a hidden state onto those directions, and---once
a token logit, logit difference, or contrast is selected---multiplies the
coefficients by the projections to produce signed feature contributions plus
an explicit residual in original logit coordinates.

In high-fidelity Qwen settings, SRP preserves held-out contrast signs at
\(0.949\)--\(0.958\) and keeps median relative reconstruction error below
\(0.10\); on Qwen3.5-2B it cuts median error from \(0.260\) (best baseline) to
\(0.081\). The same fixed basis then lets us compare score choices, prompt
contexts, residual-stream components, and edits that move specified lexical
scores at the readout, all within one decomposition.
\end{abstract}
