\section{Introduction}

Language models map hidden states to vocabulary logits through the final
unembedding matrix, or LM head; we call this the \emph{readout}.
Lens-style methods inspect hidden states in vocabulary space, either through the
LM head or through a learned lens
\citep{nostalgebraist2020,belrose2023tuned,pal2023future,ghandeharioun2024patchscopes}.
These methods show which tokens or scores a hidden state favors, but once a
token, contrast, or margin is selected, the inspected quantity remains one dense
dot product with an unembedding row or readout direction. This leaves a local
gap: the score does not identify which shared readout-side directions support or
oppose the target, or how much residual remains after a sparse account.

Sparse Readout Prism (SRP) addresses this gap by separating the basis from the
target. It learns a sparse dictionary for final-unembedding rows: each row
receives sparse token-row coefficients over shared directions plus a row
reconstruction residual. We call the shared directions
\emph{readout features}: features of LM-head rows, not activation-SAE features
of hidden states. SRP uses sparse-autoencoder and dictionary-learning machinery
\citep{makhzani2013ksparse,bricken2023monosemanticity,cunningham2023sparse,gao2024scaling},
but trains on unembedding rows rather than hidden-state activations.

After fitting, a hidden state enters through projections onto readout features.
Target selection is separate: a \emph{scalar readout target} is a selected
linear function of unembedding rows, such as a token logit, pairwise logit
difference, group contrast, reference contrast, or top-competitor margin. The
target supplies coefficients \(\beta_i\), the context supplies projections
\(h^\top d_i\), and their product
\(c_i=\beta_i h^\top d_i\) is a \emph{signed feature contribution}. Positive
terms raise the chosen scalar target and negative terms lower it. Feature terms,
optional offset, and residual give a local score decomposition in original logit
units.

\Cref{fig:main-lens-prism-comparison} shows this identity for a fixed
\texttt{verify}-minus-\texttt{assume} margin.

Replacement, target-reconstruction, sign, error, and baseline checks gate
interpretation. In the Qwen settings selected by these checks, the fixed basis
and selected targets preserve held-out contrast signs at \(0.949\)--\(0.958\)
with median relative reconstruction error below \(0.10\).

Within checked regimes, local decompositions expose support and opposition,
compare target and context effects, compose with residual-stream attribution,
and identify candidate readout-side edit directions.
Across these uses, claims remain tied to feature ids, signed terms, and
residuals; feature labels summarize high-coefficient vocabulary rows.

The paper contributes:
\begin{itemize}
    \item a sparse dictionary factorization of the final unembedding / LM head
    into token-row coefficients and shared readout feature directions;
    \item a scalar readout-target formalism that converts token logits, pairwise
    differences, group contrasts, reference contrasts, and top-competitor
    margins into signed feature contributions plus residuals;
    \item a fidelity evaluation suite for gating interpretation of SRP
    decompositions;
    \item readout-level analyses of target choice, prompt context,
    feature-resolved residual-stream attribution, and candidate readout-side edit
    directions, restricted to cases with the relevant fidelity checks.
\end{itemize}
