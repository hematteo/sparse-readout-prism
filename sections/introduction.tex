Transformer language models score each vocabulary token by a dot product
between a final hidden state \(h\in\R^d\) and a row \(w_t\) of the
unembedding matrix \(\WU\in\R^{|\mathcal{V}|\times d}\), the \emph{LM
head} or \emph{readout}. Lens-style
methods~\citep{nostalgebraist2020,belrose2023tuned,pal2023future,ghandeharioun2024patchscopes}
reuse this map on intermediate hidden states and report what it yields:
vocabulary logits, token rankings, or distributions. They differ in what
they do to the state first, with the logit lens applying \(\WU\)
unchanged and \emph{fitted} lenses first transporting the state through
a map estimated from a corpus. The token, however, is an ambiguous unit for
that report. It names the object of the report, while the structure the
readout used to produce it stays hidden, and the two come apart in both
directions. Every sense of \texttt{bug}
shares one unembedding row, so the row's score conflates readings the
readout geometry keeps apart. Conversely, near-synonyms and
translation-equivalent tokens score through rows that share dominant
directions, so distinct tokens can stand in for one another as reports
of the same structure. Token identity is too coarse for the first
mismatch, too fine for the second. Lens methods supply much of the
evidence behind interpretability claims about intermediate computation:
which distinctions a hidden state carries, and where in the stack a
behavior appears. Auditing and targeted
intervention build on such claims, and each is stated in the unit
the lens reports. Two Jacobian lenses \citep{gurnee2026workspace} that
differ only in the corpus their transport was fitted on read the same
frozen hidden state and report different languages, the kind of reading
used to infer which language a model computes in, while a single readout
structure carries both (\S\ref{subsec:cross-lens}).

Consider one hidden state from a software-context prompt. Does the
readout favor the continuation \texttt{bug} over \texttt{insect}? The
logit lens reports the margin
(Figure~\ref{fig:main-lens-prism-comparison}, top). Sparse
Readout Prism (SRP) asks how that margin is composed on the readout side:
which readout directions support it, which oppose it, and how much remains
unexplained (Figure~\ref{fig:main-lens-prism-comparison}, bottom). The
answer moves with context. In an insect-context prompt, the support for
the same token comes instead from insect-sense readout directions
(\Cref{fig:selected-readout-prism-examples}). The converse ambiguity
resolves in the same basis, where the two-lens disagreement above turns
out to be a disagreement about surface form alone and the decomposition
names the single feature carrying both readings (\Cref{sec:beyond-token}).

SRP applies dictionary learning directly to LM-head rows, writing each
row as sparse coefficients over a shared overcomplete basis, plus a
residual. We call the shared directions \emph{readout features},
features of LM-head rows rather than of hidden-state
activations. A lens score is always a score for something selected, one
token's logit or a difference of two. Selecting fixes a direction
\(q\) built from those rows. Any such fixed combination is a
\emph{readout score}, the zero-sum case comparing alternatives a
\emph{contrast}, and its signed value a \emph{margin}. The row-side
coefficients then combine with hidden-state projections to give signed
per-feature contributions in original logit units, plus an explicit
residual (\S\ref{sec:method-local-score}). TopK dictionary fitting is a
standard primitive~\citep{makhzani2013ksparse,gao2024scaling}. Our
contribution is the interface it induces once applied to the readout, a
single basis in which every selected score can be read and any two
readings compared.

Nearby accounts differ in what they decompose. Activation SAEs decompose
the hidden state itself, learning corpus- and layer-specific bases for
\(h\)~\citep{bricken2023monosemanticity,cunningham2023sparse,gao2024scaling},
whereas the SRP basis comes from the weights alone and exists before any
prompt. Residual-stream attribution decomposes how components wrote the
hidden state. SRP decomposes which directions a selected score reads
from it, so the two are complementary. Direct LM-head geometry works on the
same rows SRP factorizes, but is never held to reproducing a particular
score.

We make three contributions:
\begin{itemize}
    \item \emph{A compositional readout-feature interface.} A weight-only
    sparse factorization of the LM head that turns any selected token
    logit, logit difference, or fixed vocabulary-row combination into
    readout-feature contributions plus an explicit residual in
    logit units, without prompt-, task-, or layer-specific
    training. Unlike accounts built on row geometry, it is held to
    reproducing the score it decomposes, and reports the error each
    time (\Cref{sec:method}).
    \item \emph{Structure that outperforms row-geometry baselines,
    reproduces across runs, and agrees with ablation.} On the six of
    eight models whose factorized head
    passes a replacement check, SRP reconstructs selected scores and
    recovers token groupings more reliably than methods built directly
    on LM-head row geometry. Its explanations reproduce across
    independent training runs, and its feature contributions match the
    measured effect of removing individual feature directions from the
    hidden state (\Cref{sec:results}).
    \item \emph{A correction to how fitted-lens readings are used.}
    Swapping a Jacobian lens's fitting corpus from English to Chinese
    changes the surface language it reports on identical hidden states,
    yet one SRP feature remains dominant on 77 of 80 prompts, and a
    same-script pair and a second lens construction behave the same way.
    The reported language follows the fitting corpus (\emph{corpus
    conditionality}), not the structure being read, so a
    working-language conclusion drawn from a fitted lens's token
    readings stays underdetermined until that corpus is varied
    (\Cref{sec:beyond-token}).
\end{itemize}
