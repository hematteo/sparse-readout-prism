\section{Introduction}

Language models map hidden states to vocabulary logits through the final
unembedding matrix, or LM head; we call this final map the \emph{readout}.
Lens-style methods inspect hidden states through vocabulary distributions,
future-token predictions, continuations, or descriptions, using the LM head,
learned lens maps, or representation-patching interfaces
\citep{nostalgebraist2020,belrose2023tuned,pal2023future,ghandeharioun2024patchscopes}.
These methods answer which tokens or contrasts a hidden state favors, but each
final-readout score is still a dense dot product with an unembedding row or
logit-difference direction.

For debugging surprising predictions and auditing readout-level evidence, this
single score is often too coarse. After a programming prompt, for example, a
model may rank \texttt{bug} highly; a lens output shows that score, but not
whether output-side structure associated with insects, software defects, or
generic nouns supports it. The missing object is a sparse, reusable basis for
the readout itself, together with checks that this basis preserves the original
LM-head behavior.

Sparse Readout Prism (SRP) addresses this gap by factorizing the final readout.
It learns a sparse dictionary for final-unembedding rows: each token row is
expressed as sparse coefficients over shared directions plus a reconstruction
residual. We call the shared directions \emph{readout features}: features of
LM-head rows, not activation-SAE features of hidden states. SRP uses
sparse-autoencoder and dictionary-learning machinery
\citep{makhzani2013ksparse,bricken2023monosemanticity,cunningham2023sparse,gao2024scaling},
but trains on unembedding rows rather than hidden-state activations.

The learned basis can be used before any token, contrast, or margin is selected.
SRP projects a hidden state onto the readout feature directions, giving a
score-independent view of that state in readout-feature coordinates. The same
factorization can reconstruct the full logit vector and replace the LM head,
providing a direct check that the sparse basis preserves the original readout.
Only after a score is selected do these projections become support or
opposition for that score.

A selected score---a token logit, logit difference, group or vocabulary-mean
contrast, or top-competitor margin---fixes a readout direction. Its per-feature
coefficients, multiplied by the hidden state's projections onto the same
directions, give signed feature contributions; with an optional offset and the
residual, they reconstruct the selected score in original logit units.

Diagnostics---LM-head replacement, score reconstruction, sign agreement,
relative error, and baseline comparisons---gate interpretation. On the
high-fidelity Qwen rows of \Cref{tab:readout-query-fidelity-summary}, the
fixed basis preserves held-out contrast signs at \(0.949\)--\(0.958\) with
median relative reconstruction error below \(0.10\). Under those gates, SRP
supports readout-level analyses of how feature contributions shift with prompt
context, how residual-stream components add into a selected score, and which
readout directions move candidate lexical scores without retraining.

The paper contributes:
\begin{itemize}
    \item a sparse dictionary factorization of the LM head into token-row
    coefficients and shared readout feature directions;
    \item a reusable basis for full readout reconstruction or replacement and
    for score-independent hidden-state projections;
    \item local decompositions of standard readout scores into signed feature
    contributions plus explicit residuals;
    \item readout-level analyses of score choice, prompt context,
    residual-stream attribution, and candidate readout-side edits.
\end{itemize}
