\section{Introduction}

Language models map hidden states to vocabulary logits through the final
unembedding matrix, or LM head; we call this interface the \emph{readout}.
Lens-style methods inspect hidden states in vocabulary space, either through the
LM head or through a learned lens
\citep{nostalgebraist2020,belrose2023tuned,pal2023future,ghandeharioun2024patchscopes}.
A lens can show which tokens or scores a hidden state favors. However, once a
token, contrast, or margin is selected, the object being inspected is still one
dense scalar dot product with an unembedding row or readout direction. The score
leaves implicit which shared readout-side directions support it, which oppose
it, and how much error remains after a sparse account of that score.

This creates a gap between vocabulary-space inspection and feature-level
readout analysis. The needed object is a selected scalar readout target
expressed as sparse, signed, residual-checked readout-side terms in the original
logit units. We address this local problem: for a fixed hidden state and a fixed
linear target, decompose the selected readout score while carrying the
reconstruction residual explicitly. The result is a readout-level decomposition
whose fidelity can be checked for the target at hand.

We introduce Sparse Readout Prism (SRP). Operationally, SRP first learns a
sparse dictionary for rows of the final unembedding matrix. Each vocabulary row
receives sparse token-row coefficients over shared directions, plus a row
reconstruction residual. We call the shared directions \emph{readout features}:
they are features of the LM-head rows, not activation-SAE features of hidden
states. Thus SRP uses sparse-autoencoder and dictionary-learning machinery
\citep{makhzani2013ksparse,bricken2023monosemanticity,cunningham2023sparse,gao2024scaling},
but trains the dictionary on unembedding rows rather than on a distribution of
hidden-state activations.

After the readout features are fixed, the hidden state enters this decomposition
through its projections onto those directions. A \emph{scalar readout target} is
a selected linear function of unembedding rows, such as a token logit, pairwise
logit difference, group contrast, reference contrast, or top-competitor margin.
The target supplies coefficients \(\beta_i\) for readout feature \(i\), while the
context supplies the projection \(h^\top d_i\). Their product
\(c_i=\beta_i h^\top d_i\) is a \emph{signed feature contribution}: positive
terms raise the chosen scalar target and negative terms lower it. The remaining
row-reconstruction term is carried through as an explicit \emph{residual}; raw
token-logit targets also report the shared offset. Feature bars are therefore
reported with their reconstruction error as a local score decomposition.

\Cref{fig:main-lens-prism-comparison} illustrates this identity on a
\texttt{verify}-minus-\texttt{assume} margin: SRP keeps the pairwise logit
difference fixed, assigns positive signed feature contributions to readout
features with labels summarizing verification/checking token rows, assigns
negative signed feature contributions to readout features with labels summarizing
assumption-related token rows, and reports the residual.

SRP reports decomposition fidelity through diagnostics: LM-head replacement,
target reconstruction, sign preservation, relative error, and baselines.
Feature-bar analyses focus on small-residual settings; for signed targets, we
also check sign preservation. In the Qwen settings selected by these checks, SRP
preserves held-out contrast signs at \(0.949\)--\(0.958\) with median relative
reconstruction error below \(0.10\).

Within these residual-checked regimes, SRP exposes supporting and opposing
readout features for the same scalar target. It also lets us compare target
choices and prompt contexts in a common basis, compose readout-feature terms with
residual-stream attribution because the terms remain linear in the hidden state,
and identify candidate readout-side edit directions. Across these uses, the
common unit is the residual-checked scalar readout decomposition. Feature labels
summarize high-coefficient vocabulary rows; the measured objects are feature ids,
signed terms, and residuals.

The paper contributes:
\begin{itemize}
    \item a sparse dictionary factorization of the final unembedding / LM head
    into token-row coefficients and shared readout feature directions;
    \item a scalar readout-target formalism that turns token logits, pairwise
    differences, group contrasts, reference contrasts, and top-competitor margins
    into signed feature contributions plus explicit residuals;
    \item a fidelity evaluation suite covering LM-head replacement, target
    reconstruction, sign preservation, relative error, and sparse-structure
    baselines;
    \item residual-checked readout-level analyses of target choice, prompt
    context, feature-resolved residual-stream attribution, and candidate
    readout-side edit directions.
\end{itemize}
