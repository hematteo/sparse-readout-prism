\section{Introduction}

Transformer language models map a final hidden state \(h\in\R^d\) to next-token logits through an unembedding matrix \(\WU\in\R^{|\mathcal{V}|\times d}\), the \emph{LM head}; row \(w_t\) is the learned direction whose dot product with \(h\) scores token \(t\). Lens-style methods~\citep{nostalgebraist2020,belrose2023tuned,pal2023future,ghandeharioun2024patchscopes} reuse this map on intermediate hidden states, exposing vocabulary logits, token rankings, or distributions. Yet once a token or contrast is selected, the inspected object remains a single dense dot product \(h^\top q\), where \(q\) is an LM-head row or row combination. We call this final map the \emph{readout}.

The decompositions most commonly paired with lens-style readouts act on the hidden-state side. Direct logit attribution (DLA) decomposes \(h=\sum_c h_c\) into contributions from earlier residual-stream components---the embedding, attention heads, and MLP layers---and reads off each component's contribution to a chosen logit~\citep{elhage2021framework,wang2022ioi,nguyen2024logitprisms}. Sparse autoencoders (SAEs) and related dictionary-learning methods learn overcomplete bases that reconstruct each input from a few active coordinates~\citep{makhzani2013ksparse,bricken2023monosemanticity,cunningham2023sparse,gao2024scaling}; applied to hidden activations, they yield sparse coordinates for \(h\). Neither decomposes the readout direction \(q\) itself.

Because token logits and logit differences are linear in LM-head rows---\(h^\top(w_A - w_B) = h^\top w_A - h^\top w_B\)---a readout-side, per-feature account in logit units requires a sparse decomposition of the LM-head rows themselves; decomposing \(h\) alone cannot produce row-side coordinates. A lens can therefore report that a state favors \texttt{verify} over \texttt{assume} (Figure~\ref{fig:main-lens-prism-comparison}A), but not which shared readout-side directions support that margin, which oppose it, or how much error a sparse account would incur. Thus DLA and activation SAEs decompose or localize \(h\), whereas SRP must decompose \(q\): a readout-side basis separates the selected direction, the context-dependent hidden-state projection, and the reconstruction residual.

Sparse Readout Prism (SRP) supplies this missing readout-side basis by applying dictionary learning directly to LM-head rows rather than to hidden activations: each token row is expressed as sparse coefficients over a shared overcomplete basis of directions, plus a residual. We call the shared directions \emph{readout features}---features of LM-head rows, in contrast to SAE features trained on hidden-state activations.

Before any token, contrast, or margin is fixed, SRP projects a hidden state onto each readout feature direction, yielding coordinates \(p_i(h)=h^\top d_i\) that are reusable across downstream score choices. The same factorization reconstructs the full logit vector and can replace the LM head outright, providing a direct check that the sparse basis preserves the original readout. Once a \emph{readout score} is selected---a token logit \(h^\top w_t\), a pairwise logit difference \(h^\top(w_A-w_B)\), or another fixed LM-head row combination---the row-side coefficients combine with these hidden-state projections to yield signed per-feature contributions in original logit units (Figure~\ref{fig:main-lens-prism-comparison}B), each checkable against the original head. In short, SRP decomposes the readout side of lens scores.

This paper makes three contributions:
\begin{itemize}
    \item \emph{A sparse factorization of the LM head.} We fit a shared
    overcomplete dictionary directly to unembedding rows; the full head can be
    reconstructed or replaced from the resulting sparse codes.
    \item \emph{Score-agnostic feature projections.} Each learned direction
    yields a per-feature projection of any hidden state, reusable across
    downstream score choices.
    \item \emph{Local score decompositions in logit units.} For any token logit,
    logit difference, or fixed row combination, SRP returns signed per-feature
    contributions plus offset and residual, all in original logit units.
\end{itemize}

Across the eight-model suite, SRP preserves contrast sign on at least \(91\%\)
of held-out logit differences. On Qwen3.5-2B, it improves held-out
score-reconstruction error over nearest-row ridge, matched-rank PCA, and
shuffle/random sparse baselines. Across models, these diagnostics identify a
sign-preserved, low-error subset (\(\rho<0.5\)) where we report local feature
readings with explicit residuals.
