\section{Introduction}

When a language model assigns a higher logit to one token than another, we want
to know not only which token won, but which output-side directions drove the
score. This matters for debugging surprising predictions and auditing
readout-level evidence. For example, after a programming prompt, a model may
rank \texttt{bug} highly; existing lens outputs show the token score, but not
whether readout structure associated with insects, software defects, or generic
nouns drove it, because the score itself remains a single dot product.

Language models map hidden states to vocabulary logits through the final
unembedding matrix, or LM head; we call this the \emph{readout}. Lens-style
methods inspect hidden states through vocabulary distributions, future-token
predictions, continuations, or descriptions, using the LM head, learned lens
maps, or representation-patching interfaces
\citep{nostalgebraist2020,belrose2023tuned,pal2023future,ghandeharioun2024patchscopes}.
These approaches change which map is read, but the final-readout score still
arrives as a single dot product.

Sparse Readout Prism (SRP) addresses this gap by separating the readout basis
from the score being decomposed. It learns a sparse dictionary for
final-unembedding rows: each row is expressed as sparse coefficients over
shared directions plus a reconstruction residual. We call the shared directions
\emph{readout features}: features of LM-head rows, not activation-SAE features
of hidden states. SRP uses sparse-autoencoder and dictionary-learning machinery
\citep{makhzani2013ksparse,bricken2023monosemanticity,cunningham2023sparse,gao2024scaling},
but trains on unembedding rows rather than hidden-state activations.

After fitting, a hidden state enters via its projections onto readout features.
A chosen score fixes a readout direction: standard cases include a token logit
\(h^\top w_A\), a pairwise logit difference \(h^\top(w_A-w_B)\), a group or
vocabulary-mean contrast, and a top-competitor margin. This direction
supplies coefficients \(\beta_i\), the context supplies projections
\(h^\top d_i\), and their product \(c_i=\beta_i h^\top d_i\) is a
\emph{signed feature contribution}. Positive terms raise the chosen score and
negative terms lower it. Feature terms, an optional offset, and the residual
together give a local score decomposition in original logit units.

\Cref{fig:main-lens-prism-comparison} shows this identity for a fixed
\texttt{verify}-minus-\texttt{assume} margin.

We gate interpretation with LM-head replacement, score reconstruction, sign
agreement, relative error, and comparison against null and reference baselines.
In the high-fidelity Qwen rows in
\Cref{tab:readout-query-fidelity-summary}, the fixed basis preserves held-out
contrast signs at \(0.949\)--\(0.958\), with median relative reconstruction
error below \(0.10\).

This lets us ask readout-level questions a logit lens alone does not answer:
how feature contributions shift with prompt context, how residual-stream
components add into a selected score, and which readout directions move
candidate lexical scores without retraining. Claims remain tied to feature
ids, signed terms, and residuals; feature labels are descriptive summaries of
high-coefficient vocabulary rows.

The paper contributes:
\begin{itemize}
    \item a sparse dictionary factorization of the LM head into token-row
    coefficients and shared feature directions;
    \item a way to apply this fixed basis to standard readout scores--token
    logits, logit differences, group contrasts, vocabulary-mean contrasts, and
    top-competitor margins--yielding signed feature contributions plus
    residuals;
    \item diagnostics and baselines that identify when these decompositions
    preserve the original readout scores;
    \item validation-gated analyses of score choice, prompt context,
    feature-resolved residual-stream attribution, and candidate edit directions.
\end{itemize}
