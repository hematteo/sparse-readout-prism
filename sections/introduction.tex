\section{Introduction}

Language models map hidden states to vocabulary logits through the final
unembedding matrix, or LM head; we call this final map the \emph{readout}.
Lens-style methods inspect hidden states through vocabulary distributions,
future-token predictions, continuations, or descriptions, using the LM head,
learned lens maps, or representation-patching interfaces
\citep{nostalgebraist2020,belrose2023tuned,pal2023future,ghandeharioun2024patchscopes}.
These methods show which tokens or contrasts a hidden state favors, but each
final-readout score is still a dense dot product with an unembedding row or
logit-difference direction.

For debugging surprising predictions and auditing readout-level evidence, this
single score is often too coarse. After a programming prompt, for example, a
model may rank \texttt{bug} highly; a lens output shows that score, but not
whether output-side structure associated with insects, software defects, or
generic nouns supports it. The lens reports the scalar score, not a sparse
readout-side account of that score. What the lens lacks is a sparse, reusable
basis for the readout matrix itself, paired with checks that this basis
preserves the original LM-head behavior.

Sparse Readout Prism (SRP) supplies this basis by factorizing the LM-head
matrix directly: each token row is expressed as sparse coefficients over a
shared dictionary of directions plus a residual. We call the shared directions
\emph{readout features}---features of LM-head rows, in contrast to
sparse-autoencoder features trained on hidden-state activations. SRP uses
sparse-autoencoder and dictionary-learning machinery
\citep{makhzani2013ksparse,bricken2023monosemanticity,cunningham2023sparse,gao2024scaling},
but trains on unembedding rows rather than hidden states.

Before any score is selected, SRP projects a hidden state onto the readout
feature directions, giving a score-independent view in readout-feature
coordinates; the same factorization can reconstruct the full logit vector and
replace the LM head, checking that the sparse basis preserves the original
readout. Once a score---a token logit, logit difference, group or
vocabulary-mean contrast, or top-competitor margin---is selected, its
per-feature coefficients multiply the hidden-state projections to give signed
contributions that, with an optional offset and the residual, reconstruct the
selected score in original logit units.

The paper contributes:
\begin{itemize}
    \item \emph{Sparse readout factorization.} SRP factorizes the final
    unembedding/LM head into sparse token-row codes over shared readout feature
    directions, yielding a readout-specific sparse basis that can reconstruct or
    replace the full readout.
    \item \emph{Score-independent projections.} Projecting hidden states onto
    the learned directions gives readout feature projection vectors before any
    token, contrast, or margin is selected.
    \item \emph{Local score decompositions.} For selected token logits, logit
    differences, and fixed LM-head row combinations, SRP turns selected-direction
    coefficients and hidden-state projections into signed feature terms plus
    offset and residual terms in logit units.
    \item \emph{Readout analyses under diagnostics.} Replacement fidelity, score
    reconstruction, sign agreement, relative error, and baseline comparisons
    identify regimes where the same basis supports analyses of score choice,
    prompt context, residual-stream attribution, and constrained readout-side
    edits.
\end{itemize}
