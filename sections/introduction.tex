\section{Introduction}

Language models map hidden states to vocabulary logits through the final
unembedding matrix, or LM head; we call this interface the \emph{readout}.
Lens-style methods inspect hidden states in vocabulary space, through the LM head
or through a learned lens
\citep{nostalgebraist2020,belrose2023tuned,pal2023future,ghandeharioun2024patchscopes}.
A logit-lens probe asks: what vocabulary evidence does this hidden state expose?
This view is useful, but each selected logit or contrast remains a dense dot
product with an unembedding row or readout direction. It identifies favored
tokens without showing which shared readout directions support or oppose the
score, or what residual remains after a sparse decomposition.

We introduce Sparse Readout Prism (SRP), a sparse feature decomposition for
logit-lens readouts. SRP applies sparse-autoencoder and dictionary-learning
machinery to the LM head itself
\citep{makhzani2013ksparse,bricken2023monosemanticity,cunningham2023sparse,gao2024scaling},
yielding a sparse dictionary factorization of the final unembedding matrix.
Vocabulary rows receive sparse token-row coefficients over shared SAE decoder
directions. We call these directions \emph{readout features}: they are features
of the final readout matrix rather than activation-SAE features of hidden states.
For a hidden state, projection onto these directions gives
\emph{readout feature projections} before any token, contrast, or margin is
selected. A chosen linear function of unembedding rows is a \emph{scalar readout
target}; it supplies target coefficients that turn the projections into
\emph{signed feature contributions} plus explicit reconstruction residuals. We
call the resulting target-conditioned object a \emph{local score decomposition}.

\Cref{fig:main-lens-prism-comparison} illustrates this identity on a
\texttt{verify}-minus-\texttt{assume} margin: SRP keeps the pairwise logit
difference fixed, assigns positive signed feature contributions to readout
features with labels summarizing verification/checking token rows, assigns
negative signed feature contributions to readout features with labels summarizing
assumption-related token rows, and reports the residual.

SRP operates on scalar readout targets: token logits, pairwise logit differences,
group contrasts, or top-competitor margins.
For a fixed hidden state and target, the terms are local and checkable against
the original score and residual. Diagnostics identify settings where the sparse
terms preserve selected readout scores closely enough for local analysis. In the
Qwen settings selected by these checks, SRP preserves held-out contrast signs at
\(0.949\)--\(0.958\) with median relative reconstruction error below \(0.10\).

The paper contributes:
\begin{itemize}
    \item a sparse dictionary factorization of the final unembedding / LM head
    that defines a sparse feature basis for the readout;
    \item a scalar readout-target formalism that turns token scores, token
    contrasts, group contrasts, and margins into signed feature contributions;
    \item fidelity diagnostics for LM-head replacement, target reconstruction,
    sign agreement, relative error, and baselines, identifying when the terms
    preserve the original readout score;
    \item analyses showing how target choice, prompt context, residual-stream
    components, and constrained readout-side edits interact with the same
    readout feature basis.
\end{itemize}
