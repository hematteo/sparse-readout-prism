\section{Introduction}

Language models map hidden states to vocabulary logits through the final
unembedding matrix, or LM head; we call this interface the \emph{readout}.
Lens-style methods use this interface, or a learned variant of it, to decode
hidden states into vocabulary distributions, top-token summaries, prompted
continuations, or natural-language descriptions
\citep{nostalgebraist2020,belrose2023tuned,pal2023future,ghandeharioun2024patchscopes}. A
logit-lens probe asks a simple readout question: what vocabulary evidence does
this hidden state expose? The limitation is that each selected score remains a
dense dot product. A token logit is \(h^\top w_t\), a pairwise logit difference is
\(h^\top(w_A-w_B)\), and more general linear readout scores remain combinations
of unembedding rows. Lens-style summaries can identify favored tokens or
contrasts, but not which shared readout directions support the score, which
oppose it, or how much remains outside a sparse feature decomposition.

Sparse Readout Prism (SRP) factorizes the readout itself. It learns sparse
token-row coefficients and shared decoder directions for the LM head; we call
these directions \emph{readout features}. Given a hidden state and a chosen
scalar readout target, i.e. a selected linear function of unembedding rows, SRP
asks which reusable directions add support, which add opposition, and how much
remains in the reconstruction residual. We call this signed, target-specific
decomposition a \emph{local score account}: it accounts for one selected linear
readout score for one hidden state and target, not global model behavior.

To make these readout scores decomposable, SRP applies sparse-autoencoder and
dictionary-learning machinery to the LM head itself
\citep{bricken2023monosemanticity,cunningham2023sparse,gao2024scaling}. It
factorizes the final unembedding matrix into sparse token-row coefficients and
shared readout directions,
\[
    \WU \approx \mathbf{1}\mu^\top + ZD_{\mathrm{feat}} .
\]
The factorization gives a reusable readout-feature basis before any target is
chosen. For hidden state \(h\), \(D_{\mathrm{feat}}h\) gives readout feature
projections onto directions learned from unembedding rows, not hidden-state SAE
activations. A scalar readout target---a token logit, reference contrast,
pairwise logit difference, group contrast, or top-competitor margin---then turns
those projections into signed feature contributions plus a residual.

\Cref{fig:main-lens-prism-comparison} illustrates this identity on a
\texttt{verify}-minus-\texttt{assume} margin: SRP keeps the pairwise target fixed,
attributes support to verification/checking features, opposition to
assumption-related features, and reports the residual.

We contribute: (i) a sparse dictionary factorization of the final unembedding /
LM head; (ii) target-independent readout feature projections that scalar readout
targets convert into signed feature terms; (iii) a target formalism for token
logits, reference contrasts, logit differences, group contrasts, and margins;
(iv) fidelity diagnostics for replacement, reconstruction, sign agreement, and
baselines; and (v) low-error demonstrations showing how target choice, prompt
context, residual-stream components, and constrained readout-side edits interact
with the same readout-feature basis.
