\section{Conclusion}

Sparse Readout Prism offers an alternative unit for interpreting
vocabulary readouts. Token identity can be too coarse where one token
draws on several structures and too fine where several tokens share one.
SRP reconstructs selected scores where direct row geometry does not, and
it reproduces across independent runs. It also shows what token rankings
cannot, that differently fitted lenses report different surface
languages while one readout feature stays dominant. That dependence,
which we call \emph{corpus conditionality}, is a property of the
instrument rather than the state. A lens reading should therefore be
reported with the corpus it was fitted on and the residual it leaves.
Without that, a working-language claim cannot be told apart from a
property of the lens.
